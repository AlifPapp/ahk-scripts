This was created between 2019 and 2021 and is now archived.

## About
These are the AutoHotkey scripts I made when I first started programming. All of it was written before ChatGPT was a thing, so a lot of it is me figuring stuff out from the AHK forums and trial and error. I'm keeping it up as a memory.

## What's in here:
* **Dankmemer** - Bots that farmed Dank Memer for me by typing the commands into Discord (beg, postmemes, bets, slots, deposit and withdraw).
* **small scripts** - A few hotkeys. Switching tabs and closing programs, switching between 2 windows and writing in emoji letters on Discord.
